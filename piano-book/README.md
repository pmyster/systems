# Piano Lesson Book

A theory-first piano method that takes a complete beginner to a strong intermediate pianist.
Output format: PDF.

This project is separate from the trading system in the rest of this repository.
Nothing here imports from, or is imported by, the trading code.

## Folder layout
- `OUTLINE.md`  — the plan for the whole book (agree on this before writing lessons)
- `lessons/`    — one text file per lesson (the written explanations)
- `music/`      — sheet-music examples, written as text and turned into notation
- `build/`      — the generated PDF (produced by a script, never edited by hand)
