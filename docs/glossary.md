# Glossary

## TL;DR
- Canonical names and one-line glosses for every proper noun in the project.
- Authoritative: if you add a new proper noun anywhere, add it here in the same change.
- Skim the tables; jump to the entry you need.

## Scope
This doc owns terminology and naming. It does NOT own the design behind each concept — that lives in the cited authoritative doc.

## Prerequisites
None. This is the first doc to load.

---

## Project & architecture

| Term | Gloss | Authoritative doc |
|---|---|---|
| **Schematic** | A JSON file the engine reads as a rule (unit, part, structure, AI, event, physics, tech) | `docs/schematics.md` |
| **Schematic Schema** | JSON Schema published per Schematic kind; validated at load time | `docs/schematics.md` |
| **Editor App** | Companion desktop/tablet app for designing units; outputs Schematics | `docs/units.md`, `docs/ui-ux.md` |
| **Hot-reload** | Engine reloads changed Schematics without restarting | `docs/schematics.md` |
| **Composition** | A unit is a chassis Schematic + N part Schematics combined at load time | `docs/units.md` |

## Resources

| Term | Gloss | Authoritative doc |
|---|---|---|
| **Power** | Streaming energy resource. Generated by extractors; consumed by everything ongoing | `docs/economy.md` |
| **Scrap** | Tier-0 stockpile resource. Harvested from debris fields | `docs/economy.md` |
| **Alloy** | Tier-1 stockpile resource. Refined from Scrap + Power | `docs/economy.md` |
| **Fuel** | Tier-1 stockpile resource. Synthesized from local feedstock | `docs/economy.md` |
| **Tech Fragment** | Tier-2 stockpile resource. Recovered from Ruins; drives research | `docs/economy.md`, `docs/tech.md` |
| **Exotic Matter** | Tier-2 stockpile resource. Rare deposits + Meteor drops; enables T3+ tech | `docs/economy.md`, `docs/events.md` |
| **Biomass** | Earth-only renewable organic resource | `docs/economy.md` |
| **Helium-3** | Moon / gas-giant fusion fuel | `docs/economy.md` |
| **Water-Ice** | Mars / ice-moon feedstock for H₂/O₂ fuel | `docs/economy.md` |
| **Rare Earths** | Geology-dependent feedstock for high-end electronics | `docs/economy.md` |

## Units & combat

| Term | Gloss | Authoritative doc |
|---|---|---|
| **Chassis** | Base unit body that defines hardpoint layout and base stats | `docs/units.md` |
| **Hardpoint** | Slot on a chassis where parts mount | `docs/units.md` |
| **Part** | Mountable component: weapon, utility, mobility, defense | `docs/units.md` |
| **Stance** | Unit AI mode: Hold / Patrol / Attack-Move / Fire-at-Will / Guard | `docs/ai-behaviors.md` |
| **Compatibility Tag** | Environmental capability tag on chassis/part (e.g., `vacuum-rated`, `low-g-stable`) | `docs/physics.md`, `docs/units.md` |
| **Behavior Tree** | Schematic-defined AI decision structure | `docs/ai-behaviors.md` |
| **Archetype** | Faction-flavored weighting overlay on the behavior tree | `docs/ai-behaviors.md`, `docs/factions.md` |

## Tech

| Term | Gloss | Authoritative doc |
|---|---|---|
| **Baseline Tech** | Known from match start, faction-dependent | `docs/tech.md` |
| **Salvaged Tech** | Recovered from Ruins physically; lost if scout dies | `docs/tech.md` |
| **Researched Tech** | Refined in labs over time using Tech Fragments / Exotic Matter | `docs/tech.md` |

## Humans

| Term | Gloss | Authoritative doc |
|---|---|---|
| **Commander** | The player's persistent account-avatar. Off-map strategist. Not a unit. | `docs/humans.md` |
